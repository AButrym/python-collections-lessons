Counter

dict subclass for counting hashable objects. Missing key gives 0 and is not inserted.

c = Counter(iterable)
c[x]               # count of x (0 if absent)
c.most_common(n)   # top n as [(item, count), ...]
c.update(other)    # ADDS counts (dict.update replaces)
a + b              # adds counts
a - b              # keeps only positive results
+c                 # drops zero and negative

Pitfalls

Counter("text") counts characters; use .split() for words. Counts can reach 0 or go negative and the key stays. most_common() returns a list of tuples.

defaultdict

dict subclass that calls a factory to supply missing values. d[key] on a missing key inserts it.

g = defaultdict(list)   # group items
g[key].append(item)
n = defaultdict(int)    # count, starts at 0
s = defaultdict(set)    # group unique items
t = defaultdict(lambda: defaultdict(int))   # nested
dict(g)                 # back to a normal dict

Pitfalls

Reading d[k] inserts k; in and get() do not. Pass a callable (list, int, lambda), never a value like 0 or []. Typos in keys silently create new keys.
